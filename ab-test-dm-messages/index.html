How to A/B test your Instagram DMs

By TinkerFeed Editorial. Updated 16 October 2026.

Short answer

Write two versions of the same DM that differ in one thing, send each to half the commenters, and keep the one with more clicks after a few hundred sends each. We recommend Tadlo AI for the job: basic A/B testing is on every plan, and it picks the winner on opens, clicks and replies.

Small wording changes in a DM can change how many people click. Testing is how you find out which version works for your audience, because what works for another creator may not work for you.

This guide shows how to run a fair DM test and what is worth testing first.

What A/B testing means here

Your automation sends version A to some commenters and version B to others, at random. After enough people have received each, you compare clicks or replies. A/B testing splits two message variants and picks the winner on opens, clicks and replies. Basic A/B testing is on every plan; paid plans can change the 50/50 split.

Rules for a fair test

  • Change one thing only.
  • Run both versions at the same time, on the same reel.
  • Wait for a few hundred sends of each before deciding.
  • Decide what counts as winning before you start: clicks, replies or follows.

How long to run it

A viral reel can reach a decision in an hour; a quiet one may take a week. What matters is the number of sends, not the time. With only a few dozen sends per version, a difference is usually luck.

Reading the result

If version B gets clearly more clicks after a few hundred sends each, keep it and test the next thing. If the difference is small, both versions are about equal; keep the one you prefer and test something with bigger potential, such as the offer itself.

Common traps

  • Stopping the test the moment one version pulls ahead.
  • Testing on two different reels and calling it a test.
  • Changing the reel's caption or keyword mid-test.
  • Testing tiny wording changes when the offer is the real problem.

Build a playbook

  1. Test the first line.
  2. Then test the button text.
  3. Then test DM length.
  4. Write down each winner.
  5. Use the winning pattern as your default for new reels.

A worked example

A food creator tested two first lines on a recipe reel. Version A opened with "Hey, thanks for watching!"; version B opened with "Here's the paneer recipe you asked for." After several hundred sends each, B had clearly more clicks, because the preview told people the DM contained what they wanted. The creator kept B's pattern, naming the thing in the first line, for every reel after.

Test offers too

Sometimes the DM is fine and the freebie is weak. Test two different lead magnets on similar reels and compare emails per thousand views. The offer usually moves results more than any wording.

Frequently asked questions

Can I A/B test Instagram DMs?

Yes, with tools that support it. Tadlo AI includes basic A/B testing on every plan.

How many people do I need for a DM test?

A few hundred sends per version is a sensible minimum before deciding.

What should I test first in my DMs?

The first line, because it decides whether people read on.

Does A/B testing slow down my DMs?

No. Each commenter still gets one DM straight away; the tool just picks which version they receive.

Can I test different freebies?

Yes. Compare emails or clicks per thousand views on similar reels with different offers.
